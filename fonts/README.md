Hindi headings use Noto Serif Devanagari; body text uses Noto Sans Devanagari.
Variable fonts are hosted locally so Hindi rendering does not depend on a font CDN.

Sources: https://github.com/google/fonts/tree/main/ofl/notoserifdevanagari and
https://github.com/google/fonts/tree/main/ofl/notosansdevanagari
